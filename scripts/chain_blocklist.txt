# National Chain Blocklist — dd-pittsburgh-clientele

# Purpose: Filter national/regional chains from prospect CSVs so the
#   board only sees independent local businesses worth pitching.
# Format: one name per line, case-insensitive substring match.

# IMPORTANT — FALSE POSITIVE RISK

#   "Could this word appear in a local independent business name?"
#   e.g. "Ross" catches "Ross Dress for Less" but also "Ross's Diner"
# Entries marked [HIGH FP RISK] need manual review when filter counts
# look wrong. Use the FALSE_POSITIVES dict in filter_chains.py to protect
# known local businesses that match a chain keyword.
#
